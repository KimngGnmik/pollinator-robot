Code the geometry, dimension it, animate it, mark it up with a pencil. Runs in your browser; nothing leaves the device.

Click a part in the viewer, or put the cursor on a line, to link code and picture.
API sheet({title, units:'in'|'mm'}) · all coordinates in those units, z up, front is −y
box(x,y,z, w,d,h, o) corner at x,y,z · cyl(x,y,z, r,len, {axis:'x'|'y'|'z'}) axis starts at x,y,z · sphere(x,y,z, r)
prism([[x,z],…], y, d, {axis:'y'}) extrudes a profile (axis 'x' takes [y,z], 'z' takes [x,y])
Options on all: fill (hex or C.alu C.dark C.yellow C.red C.blue C.green C.white), alpha (0–1, see-through in 3D), pivot:[x,y,z], part
Every primitive returns a handle h with h.pos=[dx,dy,dz] and h.rot=[rx,ry,rz] in degrees about h.pivot. part({pivot, part}) makes an empty handle to group things under.
animate(t => { … }) runs every frame with t in seconds; change pos and rot inside it.
Selection: tap a part in the viewer to jump to its line; put the cursor on a line to highlight what it made.
